# 🗺️ Віртуальна карта коледжу (PWA)

Інтерактивний веб-додаток для навігації студентів та відвідувачів коледжу. Це Progressive Web App (PWA), що дозволяє швидко знаходити аудиторії, переглядати 360° панорами та отримувати важливу довідкову інформацію.

## 🚀 Основний функціонал

### 1. 🏠 Головна (Мапа)

Центральний вузол додатку для візуальної навігації.

* **Інтерактивна SVG Мапа:** Векторні плани поверхів з підтримкою зуму та переміщення.
* **Smart Search:** Глобальний пошук (Command Menu) за номером аудиторії або назвою кафедри.
* **Перемикач поверхів:** Зручний інтерфейс для зміни плану поверху.
* **Деталі кабінету:** При кліку відкривається картка (або Bottom Sheet на мобільному) з фото, описом та кнопкою переходу до 360° панорами.
* **Контрастність:** Кольорове кодування типів приміщень (навчальні, адміністративні, санітарні).

### 2. 📖 Довідник

Текстовий каталог для пошуку за категоріями ("Що я шукаю?", а не "Де це?").

* **Структурований список:**
* 🏢 **Адміністрація** (Директор, Бухгалтерія).
* 🎓 **Кафедри** (Циклові комісії).
* 🍔 **Інфраструктура** (Їдальня, Бібліотека, WC).


* **Навігація:** Кнопка "Показати на мапі" біля кожного пункту автоматично переносить користувача на потрібний поверх і підсвічує об'єкт.

### 3. 🛡️ Безпека

Критично важливий розділ для надзвичайних ситуацій.

* **Укриття:** Кнопка швидкого доступу до схеми маршруту в бомбосховище.
* **Евакуація:** Спрощені схеми виходів.
* **Екстрені контакти:** Клікабельні номери охорони, медпункту та екстрених служб.

### 4. ❓ FAQ (Допомога)

Відповіді на часті запитання першокурсників.

* Розклад дзвінків.
* Інструкції з підключення до Wi-Fi.
* Розташування деканату та інших ключових точок.
