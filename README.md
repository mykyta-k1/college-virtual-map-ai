# Віртуальна карта коледжу

## Описання проєкту

Інтерактивний вебсайт для навігації студентів та відвідувачів коледжу. Основна мета — створити інструмент, який допоможе новачкам не загубитися в коридорах, знайти потрібну аудиторію, кафедру чи навіть їдальню. Це інтуїтивна альтернатива звичайним картам, що надає панорамний досвід переміщення по коледжу.

## Мета проєкту

- Спростити навігацію для новачків та відвідувачів
- Забезпечити швидкий доступ до інформації про аудиторії та кабінети
- Створити зручний інтерфейс для пошуку конкретних локацій

## Сценарій використання

Користувач заходить на сайт і одразу може здійснювати переміщення по коледжу, або скористатися мапою для пошуку конкретного кабінету:

1. На сайті завантажується базова панорама (напр. вхід коледжу)
2. При натисканні кнопки "Мапа/пошук" вспливає меню з вибором поверху та конкретного кабінету
3. Після вибору поверху відображається його план у форматі SVG
4. Користувач обирає кабінет на плані і бачить короткий опис

## Функціонал

### Основні функції:
- **Перегляд і переміщення** по коледжу з панорамним 360° переглядом
- **Пошук і навігація** по кабінетах через інтерактивну мапу
- **Інформація про кабінети** — короткий опис (до 255 символів) з назвою та призначенням
- **FAQ** — посібник з використання сайту

### Додаткові функції:
- Показ поточної позиції на мапі
- Свайп для перегляду опису кабінету на мобільних пристроях
- Окрема кнопка опису на десктопі
- Підказка при вході "Мапа — для швидкого переходу по кабінетах"

## Інтерфейс

### Макет:
- **На третині екрану** розташована кнопка "Мапа/пошук"
- **Праворуч зверху** кнопка FAQ
- **Мінімальний дизайн** орієнтований на мобільні пристрої

### Особливості:
- Інтерактивне переміщення або конкретний пошук в меню
- Масштабована мапа для телефонів
- Без header та footer (максимальна площа для контенту)
- Короткий опис кабінету — 255 символів для швидкого читання

## Технологічний стек

- **Image Viewer:** [Pannellum](https://pannellum.org/) — для 360° панорамного перегляду
- **Інтерактивна мапа:** SVG для перегляду планів поверхів
- **Frontend:** HTML, CSS, JavaScript

## Технічні деталі

### Створення контенту:
- Фото у 360° можуть бути створені за допомогою мобільного додатка для сферичної фотографії

### Структура даних:
- Панорамні зображення вхідних точок коледжу
- SVG плани кожного поверху з інтерактивними кабінетами
- База даних інформації про кабінети (назва, призначення, опис)

## MVP

Мінімально життєздатний продукт включає:
- Панорамний перегляд вхідної точки коледжу
- Функціональна мапа з виділенням поверхів та кабінетів
- Пошук та інформація про конкретний кабінет
