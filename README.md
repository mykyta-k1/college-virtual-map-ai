# 🗺️ College Virtual Map AI (PWA)

Інноваційний інструмент для навігації студентів, викладачів та гостей коледжу. Цей проект поєднує інтерактивну карту приміщень, розумний пошук та AI-асистента для швидкого орієнтування в навчальному закладі.

## 🎯 Мета проєкту

Створити інтуїтивно зрозуміле середовище, яке допоможе новачкам та гостям коледжу легко знаходити потрібні аудиторії, кафедри, адміністративні кабінети чи зони відпочинку. Проєкт покликаний стати надійним провідником, що зменшує стрес від пошуку локацій у незнайомому просторі, використовуючи сучасні веб-технології та штучний інтелект.

---

## ✨ Основні можливості

*   **🗺️ Інтерактивна карта:** Деталізовані та масштабовані SVG-плани поверхів із чітким позначенням усіх кабінетів.
*   **🔍 Розумний пошук:** Миттєвий пошук аудиторій за номером, назвою або **прізвищем викладача**.
*   **🤖 AI Асистент:** Чат-бот на базі штучного інтелекту, який відповідає на запитання про розташування об'єктів та може автоматично прокладати маршрути або показувати локації на карті.
*   **📍 Побудова маршрутів:** Система навігації, що прокладає найкоротший шлях між двома точками, враховуючи переходи між поверхами.
*   **👀 360° Панорами:** Віртуальні тури по ключових локаціях (холи, великі аудиторії) для кращого орієнтування.
*   **📱 PWA (Progressive Web App):** Можливість встановлення як мобільного додатку, робота офлайн (частково) та швидкий доступ.
*   **ℹ️ Детальна інформація:** Перегляд розкладу викладачів, описів кабінетів та контактної інформації.

## 🛠️ Використані технології та джерела

Проєкт побудований на сучасному стеку технологій:

*   **[React](https://react.dev/) + [Vite](https://vitejs.dev/):** Швидкий та ефективний фронтенд фреймворк.
*   **[TypeScript](https://www.typescriptlang.org/):** Для надійності коду та типізації.
*   **[Tailwind CSS](https://tailwindcss.com/) + [Shadcn UI](https://ui.shadcn.com/):** Для створення стильного, адаптивного та доступного інтерфейсу.
*   **[Fuse.js](https://www.fusejs.io/):** Потужний движок для швидкого "нечіткого" пошуку (fuzzy search).
*   **[ngraph](https://github.com/anvaka/ngraph.path):** Бібліотека для роботи з графами та пошуку шляхів (A* алгоритм).
*   **[Pannellum](https://pannellum.org/):** Легковаговий переглядач панорамних зображень.
*   **[Lucide React](https://lucide.dev/):** Набір гарних та послідовних іконок.
*   **[Vaul](https://vaul.emilkowal.ski/):** Компонент "Drawer" для мобільних пристроїв.

## 🚀 Як запустити проєкт

### 1. Клонування репозиторію
```bash
git clone <repository-url>
cd college-virtual-map-ai
```

### 2. Встановлення залежностей
```bash
npm install
```

### 3. Налаштування змінних оточення (ОБОВ'ЯЗКОВО)
Створіть файл `.env` або `.env.local` в корені проєкту та вкажіть наступні налаштування:

```env
# URL зовнішнього сервісу AI Worker (для роботи чат-бота)
VITE_AI_WORKER_BASE_URL=https://your-ai-worker-service.com/api/chat

# API ключ для доступу до AI сервісу
VITE_AI_API_KEY=your_secure_api_key

# Пошта підтримки (для форми зворотного зв'язку)
VITE_SUPPORT_EMAIL=support@college-map.ai
```

> ⚠️ **Важливо:** Без валідних `VITE_AI_WORKER_BASE_URL` та `VITE_AI_API_KEY` функціонал AI чату буде недоступний або працюватиме некоректно. AI чат реалізований як відокремлений мікросервіс без підтримки стрімінгу.

### 4. Запуск у режимі розробки
```bash
npm run dev
```
Відкрийте браузер за адресою `http://localhost:5173` (або іншою, вказаною в консолі).

### 5. Збірка для продакшну
```bash
npm run build
```
Готові файли будуть у папці `dist`.

## 📱 Встановлення як додаток (PWA)
Цей сайт можна встановити на телефон або комп'ютер як окремий додаток:
1.  Відкрийте сайт у браузері (Chrome/Safari/Edge).
2.  Натисніть кнопку "Встановити" (або "Додати на домашній екран") в меню браузера.
3.  Користуйтесь додатком без рамок браузера та з швидким запуском.
